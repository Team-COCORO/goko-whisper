01. ツートーン記号 SVG / CSS

四つ目綴じの結束糸・題簽・押印された丸スタンプ（桜花紋）の二色構成。最も推奨される標準ピクトグラム。

02. 単色シルエット（JIS/案内用） 1-Color Solid

駅構内標識や地図記号（POI）、モノクロ印刷にも最適なネガポジ切り抜き型の単色シルエット。

03. ミニマル線画（Line UI） 2px Stroke

現代のWebアイコンセット（Feather / Lucide）と完全に調和する幾何学的な2px線画シンボル。

04. スクワークル・アプリバッジ App Tile

iOS / Android のアプリアイコンやファビコンに適した、深い藍色背景と金襴を想起させるエンブレム。

05. 純CSSピクトグラム Pure CSS

外部SVGや画像ファイル不要。1つのHTMLタグと疑似要素（`::before` / `::after`）だけで描画。

📜 明治集印帳ピクトグラムの4大構成要素

  • 1
    四つ目綴じ（4-Hole Stab Stitching）：
    西洋の洋装製本と決定的に区別する和装本の象徴。背表紙に並ぶ「縦4点の穴と結束糸」をミニマルなドットや点線で抽象化。
  • 2
    題簽（Title Slip Rectangle）：
    表紙の右上に縦長に貼られた表題紙。通常の手帳ピクトグラムと一目で区別できる和風タイポグラフィ領域。
  • 3
    朱肉の二重丸スタンプ印（Vermilion Seal）：
    単なる「ノート」ではなく「スタンプ帳・印譜帖」であることを瞬時に伝えるため、中央下部にアクセントカラー（朱色）の印影を配置。
  • 4
    角裂（Spine & Corner Guards）：
    本の四隅と背を補強する伝統工芸の三角切り返し。ピクトグラムにクラフト感と時代感を与えます。
