画面一覧

ui.html の各画面を、動かさずに開ける静的な HTML です。操作の確認は ui.html です。

  1. ホーム（初めて）名前を残す前。地図と名前欄。
  2. ホーム（名前を残したあと）名前欄は出ない。スタンプはまだ無い。
  3. QR着地（名前の前）QRを開いたが、名前を残すまで押印しない。
  4. 囁きスタンプ帳を閉じたあとに一度出る。
  5. 案内三つ未満。残っている場所が分かる。
  6. 三つ揃い（名前の前）スタンプは揃ったが、名前がまだ無い。
  7. ゴール（4桁）発行された番号。スタッフに提示する。
  8. ゴール（5分経過）番号は隠れている。再表示できる。
  9. ゴール（スタッフ消込）暗証番号が4桁そろうまで完了できない。
  10. ゴール（通信失敗）番号は端末では作らない。
  11. 受取完了消込が済んだ端末。
  12. 配布終了新しい端末は番号をもらえない。
  13. 食品模擬店の紹介。
  14. プレゼント（未達）三つ揃うまで「ゴールへ進む」は押せない。
  15. プレゼント（ゴールへ進める）三つの押印と囁きのあと。
  16. スタンプ帳（まだ無い）開いただけでは押印しない。
  17. スタンプ帳（押印済み）次の見開き。模擬店と五高記念館に印がある。
  18. 残数受付リーダー用。ナビには出ない。
  19. 記録不可このブラウザでは進行を保存できない。
